A leaderboard is only as honest
as whoever can't edit it.

Usalama checks whether a project's claimed Arkiv usage matches its actual on-chain entities — then publishes the verdict as an entity itself, signed by the auditor's own wallet. Not even Usalama can quietly fix a bad score later.

terminal 
# audit a project, check it against Tiramisu, publish the verdict
usalama audit ./my-project --repo github.com/me/my-project --publish

# every report is a real, signed Arkiv entity — verify it yourself
usalama list github.com/me/my-project
